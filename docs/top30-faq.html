🔍 Estrategia de identificación de productos Afecta 8 de 30 preguntas

Los clientes no usan SKU ni códigos. Dicen "olla tramontina grande", "las sartenes antiadherentes" o "abrelatas". El bot necesita encontrar el producto correcto en la base de datos a partir de texto libre.

Matching en 4 capas — cada capa suma un score. El bot usa el mejor match o presenta opciones si hay varios resultados cercanos:

Claude NLP
Claude Haiku extrae del mensaje: producto, marca, medida y cantidad. Normaliza el texto antes de buscar.
"Quiero 12 cajas de la olla tramontina 24" → { query: "olla tramontina 24", qty: 12 }
Aliases
Tabla product_aliases con nombres comunes curados: sinónimos, abreviaturas, marcas, categorías. Score más alto.
"abrelatas" → todos los Abrelatas · "cuch. asado" → Cuchillo Asado · "tramontina" → marca Tramontina
Trigrama
Búsqueda fuzzy con pg_trgm sobre products.description. Tolera errores de tipeo y coincidencias parciales.
"tramotina" → Tramontina (typo) · "sarten antia" → Sartén Antiadherente (parcial)
Substring
Fallback con ILIKE y match por código de producto. Último recurso para textos que no trigonean.
"nylon" → Espátula Nylon, Cucharón Nylon · "TA-2401" → match por código

Función SQL: wa_product_match(texto) → devuelve top 5 productos con score. Versión con precio: wa_product_match_with_price(texto, customer_id) → aplica descuento del cliente.

Si el score más alto es > 0.7 → usar directo. Si hay varios > 0.4 → presentar opciones. Si ninguno > 0.15 → pedir que aclare.
