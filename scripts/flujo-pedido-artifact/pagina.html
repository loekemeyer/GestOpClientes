🛒 Qué pasa cuando se hace un pedido web

Paso a paso, desde que el cliente confirma hasta que lo recibe

El cliente recibe el pedido por:
👤
Pablo confirma el pedido en la web
loekemeyer.com · el pedido queda guardado y se envía al sistema de gestión

🛡️ Antes de cada envío, siempre 3 controles

1. ¿Tiene teléfono agendado?Si no, no sale nada y no queda registro.
2. ¿Ya se mandó antes?Cada aviso se manda una sola vez por pedido.
3. ¿Está abierta la llave de envíos?Si está cerrada, el mensaje espera en cola.
