Cuando un cliente le escribe al bot

Sin estado por turno: cada mensaje entra por acá. Primero identifica por número; después distingue saludo de request (cualquier consulta, duda o pedido). Se resuelve por el camino más barato — FAQ antes que IA, IA antes que humano. En naranja lo que cambia respecto de hoy.

👤 ¿Un vendedor está atendiendo?

Si un humano tomó la charla (modo=humano), el bot no pisa. Cuando el vendedor termina (o vence el modo), el bot vuelve a atender si el cliente reinicia contacto. → humano FIN

El request se resuelve por capas

FAQ→IA→humano

"Request" = todo lo que el cliente pida o pregunte: "dame el CBU", "¿cuándo llega mi pedido?", "quiero hacer un pedido", "quiero dejar una sugerencia".

1· FAQ →AUTO (texto fijo) o SEMIAUTO (plantilla + dato de Supabase). Si resuelve, corta acá. FIN
2· IA →Si la FAQ no cubre, la IA evalúa: si puede, responde (incluye armar pedido); Claude
3· humano →Si la IA no puede (o el pedido necesita persona), escala a un vendedor con aviso. → humano
